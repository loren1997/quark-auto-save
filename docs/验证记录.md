# 维护版验证记录

本机：Windows，Python 3.11；全程后台运行。

## 第三版补丁 V3.3：媒体过滤、平铺目录和默认命名

- 转存只允许白名单视频与字幕，逐层检查目录后保存文件，避免整目录夹带图片、文档或程序。候选验证同样要求视频；纯字幕和伪造视频分类的非视频文件不能通过。第二页视频、未完整分页及旁有图片的可信作品目录均有回归。
- 完整扫描确认无视频时才尝试新来源；网络失败、权限问题及扫描上限不会被当作无视频或失效。自动补集保留同作品、同季和已知年份约束，找不到可验证缺集时明确报告。
- 热门任务的工厂默认目录迁移到夸克 `/cartoon`，Aria2 根目录 `/downloads` 与任务 `save_path=cartoon` 对应 `/downloads/cartoon`。后续文件直接平铺，不附加来源或剧名目录；默认只下载视频，字幕下载需另行开启。
- 默认命名为 `片名 S01E01.原后缀`，按明确季号调整；视频与字幕保留扩展名，不转码。默认规则、第三季、字幕、自定义规则保留、旧目录与下载待办迁移均已回归。配置合并通过唯一资源 ID 处理目录改变，同时保留并发用户编辑并拒绝含糊配对。
- 本机完整测试 265 项中 264 项通过，真实 Aria2 测试因未安装 aria2c 跳过；无头 Chromium 流程通过，无 JavaScript 异常。另覆盖共享目录误认领、视频字幕去重、更名失败重试与不同任务命名变量隔离。真实 Aria2 样本及双架构构建和启动结果以 [V3.3 发布页](https://github.com/loren1997/quark-auto-save/releases/tag/maintenance-v3.3) 所附记录为准。
- 未连接用户真实夸克账号或 NAS。更新不移动、删除已有 NAS 文件；未确认用户作品缺失集的有效备用分享，不能声称已补齐。

## 第三版补丁 V3.2：Aria2 补交与中间缺集

- 修复只配置 RPC、已有热门任务未启用下载的问题：保存热门下载开关会同步旧任务；首次启用标记历史文件补交。保存后前端重新读取配置，避免运行时传入旧开关。
- Aria2 在没有新转存时也会处理历史补交及失败队列；RPC 未连接、直链失败、提交被拒绝保留待提交文件。失败子目录只重扫该目录，不重新提交其他已受理文件。日志显示 GID 表示受理，不表示下载完成；不输出 Cookie、RPC 密钥或临时直链。
- 本机 `python -m unittest discover -s tests -v`：203 项中 202 项通过，真实 Aria2 集成测试因本机未安装 `aria2c` 跳过。CI 在 Python 3.11/3.13 中安装真实 Aria2，使用临时 HTTP 样本验证 RPC、文件落盘、内容一致及重复运行不重复下载；最终结果见 [V3.2 发布页](https://github.com/loren1997/quark-auto-save/releases/tag/maintenance-v3.2)。
- 无头 Chromium 实际填写 Aria2 假参数、启用开关、保存并运行旧热门任务，确认请求携带下载与历史补交标记，密钥不进入任务；其余 UI 流程通过，无 JavaScript 异常。网盘操作使用模拟接口。
- 热门单季任务按可靠集号检测中间缺口，重复 `05` 不算两集。原样月份、别名、版本标签、空“熟肉晚点”目录、PNG、错季/错年/不同作品、候选变化、失败保留与重复运行均有回归；只补缺号，转存后的文件 ID 进入下载插件。
- 未提供真实用户 Cookie，未连接用户 NAS 的 Aria2。公开网页只读补搜未确认到本作品第 2 集的有效备用分享，部分源连接失败、公共 PanSou 探测超时；因此不能声称用户第 2 集已经补齐。自动补集依赖可验证的实际分享，无法确认集号或季别时跳过并说明。
- Python 编译、Compose/Actions YAML 解析及差异检查通过。本机没有 Docker 引擎；双架构构建、容器启动及真实 Aria2 样本测试由云端完成后发布。
