# 维护版验证记录

本机：Windows，Python 3.11；全程后台运行。

## 第三版：网页补搜与合集目录验证

- `python -m unittest discover -s tests -v`：162 项通过。覆盖网页搜索结果与正文解析、提取码分区、来源故障、代理与凭据隔离、私网/重定向限制、查询顺序、季号变体、合集子目录选择、冲突季数拒绝、国漫身份去重及原作中文别名。
- 无头 Chromium 验证查询详情展开、来源错误、周历切换、一键订阅及移动布局；无 JavaScript 异常。网盘写入使用模拟接口。
- 真实 `scripts/probe_web_search.py "大理寺日志 第三季" --title "大理寺日志 第3季"`：约 6.4 秒，从 Bing 结果中找到公开帖子的夸克分享，匿名验证到第三季目录及视频。DuckDuckGo 网络失败、帖子 HTTP 403 未使其他已取得的链接丢失。
- 真实生产入口 `Quark().find_valid_resource(...)`，只启用网页搜索，输入“大理寺日志 第3季”：约 9.3 秒，自动补搜“第三季”并验证成功；返回唯一第三季的子目录链接，未包含合集中的第一、二季。没有执行转存。
- 真实网页搜索“罗小黑战记 学前篇”取得含学前篇、旧电影等内容的合集；没有足够目标目录证据时仍拒绝自动选取，不能据此声称一键订阅已全部成功。
- 真实国漫周历核对 B站媒体身份后，移除同日 TVmaze 重复的“罗小黑战记 第3季”，保留 B站“罗小黑战记”第 43 话；当次获取 29 个不同国漫条目，数量随来源变化。
- Bangumi 真实原作关联提供“与暗黑召唤师秘密恋爱中”别名，已纳入搜索；本次对“黑暗召唤师在地下恋爱中”及该中文别名的网页查询仍未找到可验证夸克分享，不宣称已解决所有资源缺失。
- 两份 Compose 和两份 Actions YAML 解析通过；并行包的项目名、5006 端口、配置目录、代理设置与无固定容器名均通过检查。完整云端测试、双架构构建与启动结果见 [V3 发布页](https://github.com/loren1997/quark-auto-save/releases/tag/maintenance-v3) 所附记录。

搜索使用 Bing 与 DuckDuckGo；没有接入需要验证码/脚本的 Google 页面。公开网页可达性随 NAS 网络而变化，不能保证搜到所有分享。网页抓取具有数量、字节和应用层时间预算；操作系统 DNS 与缓慢响应头仍可能延长实际耗时。
