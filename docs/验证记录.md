- 无头 Chromium 验证国漫首屏和来源分组、七天切换、订阅并立即运行、重复订阅、片名对应的错误提示及手机布局；无 JavaScript 异常。写入网盘和下载使用模拟接口。
- 真实 Python 完整调用 `Quark().find_valid_resource(...)`：搜索“学生会也有洞！ (2026)”并使用目录来源的日文、英文别名，成功验证实际分享目录和视频文件，约 15.4 秒。搜索与夸克验证均为真实请求，未执行转存。
- 另对三条真实“学生会也有洞！ 生徒会にも穴はある! (2026)”分享匿名检查，确认双语标题和 MKV 视频，而非漫画文件。

本机没有 Docker 引擎；云端 ARM64 使用 QEMU，不能替代 NAS 实机测试。公共源曾间歇返回 HTTP 400 或超时，因此自动查询复用索引缓存，同时仍实时验证分享。国漫源可能漏收录或错填日期，例如实测时《完美世界》存在日期缺口；未凭印象硬写排期。TVmaze 季号与国内年番命名不同的作品可能需手动选择，不能用旧季冒充当前季。
